# Blockchain Integration

Update blockchain as an adapter to DTComm. 
- Adapter for DTComm.

Features
- Telemetry recording into blockchain
- Data integrity using cryptographic hashing
- Tamper detection for recorded telemetry
- Block validation and chain validation
- Timestamp and quality tracking
- Persistent ledger using SQLite
- Ledger synchronization between nodes
- PBFT consensus for distributed agreement
- Validator/node identity
- Fault-tolerant operation
- Chain verification after storage
- Telemetry provenance and audit trail
-Blockchain health/status monitoring
- Separation from DTComm Runtime through an adapter interface
- Scalable from single-PC → multi-PC distributed blockchain

Note: All information sources, coding and findings are researches from internet. They contribute to the build up of this project.
