## [v0.2.1] - 31/8/26

# Blockchain Integration

Added simple blockchain to DTComm. 
- Tempered free data for storage from equipment or production machines.
- Data flow nodes. 3 nodes in locally, for simulation.
- Consensus at nodes before commit to DB. Persisted data storage locally currently.
- Hash validation
- Local consensus between nodes running locally.
- Proof of concept.

Notes: All information sources, coding and findings and researches from internet. They contributes to the build up of this project.
